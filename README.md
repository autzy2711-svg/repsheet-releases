# Repsheet — ไฟล์ติดตั้ง

ที่เก็บนี้มีเฉพาะไฟล์สำหรับติดตั้งและอัปเดตแอป Repsheet **ไม่มีซอร์สโค้ด**

- `version.json` — แอปอ่านไฟล์นี้ตอนเปิด เพื่อดูว่ามีรุ่นใหม่กว่าที่ติดตั้งอยู่ไหม
- ไฟล์ `.apk` ของแต่ละรุ่นอยู่ในหน้า **Releases**

---

## ติดตั้งครั้งแรก

1. เปิดหน้า Releases แล้วโหลดไฟล์ `.apk` รุ่นล่าสุด
2. กดที่ไฟล์ที่โหลดมาเพื่อติดตั้ง
3. ครั้งแรกครั้งเดียว Android จะถามว่าอนุญาตให้ติดตั้งแอปจากแหล่งนี้ไหม ให้กดอนุญาต
   (เพราะแอปไม่ได้อยู่บน Play Store)

รองรับ Android 7.0 ขึ้นไป เฉพาะเครื่อง 64 บิต ซึ่งคือมือถือ Android
แทบทุกรุ่นตั้งแต่ราวปี 2019

## อัปเดตเป็นรุ่นใหม่

ลงทับไฟล์เดิมได้เลย **ข้อมูลการเทรนที่บันทึกไว้ไม่หาย** ไม่ต้องถอนแอปก่อน

ถ้าถอนแอปออกเมื่อไหร่ ข้อมูลจะหายทั้งหมดเพราะทุกอย่างเก็บอยู่ในเครื่อง
ยังไม่มีระบบสำรองข้อมูลขึ้นคลาวด์
